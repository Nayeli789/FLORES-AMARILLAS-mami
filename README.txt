FLORES AMARILLAS PARA MAMÁ 💛

Abre index.html en Chrome o Edge.

INTERACCIÓN:
1. Pulsa “Flores para ti”.
2. El tronco crece desde el suelo.
3. Las ramas aparecen una por una.
4. Los girasoles pequeños florecen progresivamente.
5. Al final forman una copa de flores con forma de corazón.
6. Después aparece el mensaje y, en un bloque separado, las fotografías.

IMPORTANTE:
- Mantén la carpeta “fotos” junto a index.html.
- Para publicar en GitHub Pages, sube todos los archivos y carpetas del ZIP.
